# Harness Components

這個資料夾保留 reusable 的 harness engineering 資產，包含 repo collaboration、agent workflow、shared project memory 與 verification workflow 相關元件。

## 目前內容

- `harness-engineering/`
  - repo collaboration harness starter kit
  - 包含 `AGENTS.md` / `CLAUDE.md` / `INDEX.md` / `PROGRESS.md` / `DECISIONS.md` / `MANUAL.md` 模板
  - 也包含 `harness-framework.md`、`repo-bootstrap-prompt.md`、`VERIFY.md`

後續若要把更多 harness 模板、bootstrap prompt 或 workflow 文件抽到 top-level，可繼續放在這裡，而不是放在 `skill/` 底下。
